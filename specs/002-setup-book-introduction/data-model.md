# Data Model

This feature is primarily focused on content generation and does not introduce a complex data model. The main "data" is the markdown content itself.

## Content Structure

- **Chapter**: A chapter is a collection of sections.
  - **id**: `ch1-intro-physical-ai`
  - **title**: "Chapter 1: Introduction to Physical AI"
  - **sidebar_label**: "Ch 1: Physical AI Introduction"
  - **slug**: `/chapter-1-physical-ai`

- **Section**: A section is a part of a chapter with a specific topic.

- **Diagram**: A visual representation of a concept, created using Mermaid.js.

- **Code Example**: A block of code demonstrating a concept.
