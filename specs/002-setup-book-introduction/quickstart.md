# Quickstart

This guide explains how to run the Docusaurus project locally.

## Prerequisites

- Node.js (v18 or later)
- npm or yarn

## Installation

1.  Navigate to the `ai-native` directory:
    ```bash
    cd ai-native
    ```

2.  Install the dependencies:
    ```bash
    npm install
    ```

## Running the development server

1.  From the `ai-native` directory, run the following command:
    ```bash
    npm run start
    ```

2.  Open your browser and navigate to `http://localhost:3000`.

## Building the project

To create a static build of the project, run:
```bash
npm run build
```
The output will be in the `ai-native/build` directory.
